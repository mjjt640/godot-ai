# 手绘霓虹生图提示词基线

## 全局风格

```text
2D 游戏资产，俯视角 top-down perspective，手绘涂鸦风格，粗黑轮廓线，马克笔笔触，极简上色。克制霓虹描边：紧贴黑色轮廓外侧有纤细青蓝色 cyan、电粉色 electric pink 或少量黄色 yellow 边缘光。不要大面积光晕，不要满屏发光，不要光污染。赛博废土氛围，暗色底图，角色和敌人轮廓优先，小尺寸下清晰可读。不是像素风，不是写实风，不是厚重 3D。
```

## 大地图背景

```text
生成一张大型 16:9 俯视角 2D top-down survivor 游戏战斗地图背景。

风格：手绘涂鸦 + 克制霓虹描边。地图整体必须比角色和敌人更暗、更低饱和，主色为炭黑、深灰、黑蓝、腐蚀金属褐色。少量暗淡青蓝霓虹线路用于科技感，少量电粉用于危险提示，黄色只用于稀有资源点或警告。

地图设计：地图要大，有可持续跑图和绕行空间，不是单个小房间。中心区域保持开阔，适合玩家拉扯、风筝敌人、绕圈移动。从中心延伸出至少 3 条主要通路，地图中有 2 个明显绕行区域。障碍物要制造路线选择，不能堵死玩家，不能形成封闭死胡同。

障碍物：废弃机器、能量柱、破损墙体、低矮金属路障、电缆堆、废弃终端、损坏平台。障碍主要分布在边缘和局部区域，中心不要堵死。

视觉地标：至少 3 个视觉地标，例如破损反应堆、废弃传送门、巨大电缆山、坍塌终端机、损坏能量塔。

限制：不要角色、不要敌人、不要 UI、不要文字、不要水印。不要满屏霓虹，不要复杂到看不清道路。地图服务战斗可读性。
```

## 地图 Tile / 障碍物素材板

```text
生成一张 2D 俯视角游戏地图 tile 和障碍物素材板，纯白背景 #ffffff。

风格：手绘涂鸦 + 克制霓虹描边，粗黑轮廓线，暗淡金属色调。障碍物只带极少量暗淡青蓝或电粉边缘光，不能比角色更亮。

内容：金属地砖 tile、裂缝地砖、暗色网格地砖、废弃工业机器、断裂能量柱、破损墙体、低矮金属路障、电缆堆、损坏电脑终端、破碎平台块、能量塔碎片。

要求：所有物体独立摆放，留出足够间距，方便切图。俯视角统一，正交视角，无强透视。不要角色、不要 UI、不要文字、不要水印。
```

## 玩家设定图

```text
生成一张 2D 俯视角玩家角色设定图，纯白背景 #ffffff。

角色：赛博废土幸存者，黑色短外套，拼贴轻甲，深色裤子，小型科幻手枪或拼装能量枪。粗黑轮廓线，手绘涂鸦风格。

识别色：玩家主描边为青蓝色 cyan，身体中心或武器核心有少量电粉色 electric pink 能量点缀。霓虹只贴边，不要大面积发光。

要求：俯视角或 3/4 俯视角，轮廓清楚，小尺寸下能一眼识别。设计简洁，不要过多碎细节。不要文字、不要 UI、不要水印、不要场景背景。
```

## 玩家动作帧

```text
生成一张 2D 俯视角玩家角色 sprite sheet，纯绿色背景 #00ff00。

保持同一个角色：赛博废土幸存者，黑色短外套，拼贴轻甲，小型科幻手枪，青蓝主描边，少量电粉能量核心。严格保持帧间一致性，不要换脸、换发型、换衣服、换武器。

动作：先只生成一个方向的 run 8 帧，加 idle 4 帧，shoot 4 帧，hurt 2 帧。所有帧规则网格排列，每帧大小一致、中心点一致、脚底基准线一致、间距均匀。

风格：手绘涂鸦，粗黑轮廓线，克制霓虹描边，青蓝霓虹在每帧保持稳定，不要随机闪烁。不要文字、不要水印、不要 UI、不要复杂背景。
```

## 敌人设定图

```text
生成一张 2D 俯视角敌人设定图，纯白背景 #ffffff。

敌人：小型失控工业机器人或机械感染体，由废金属、尖刺外壳和外露电线组成，有单眼或多个传感器眼睛。整体形状比玩家更尖锐、更危险。

识别色：敌人主描边为电粉色 electric pink，少量青蓝 cyan 用于机械细节或外露电缆。粗黑轮廓线，手绘涂鸦风格，霓虹发光克制。

要求：俯视角或 3/4 俯视角，轮廓清楚，小尺寸下能看出朝向和威胁感。不要文字、不要水印、不要场景背景。
```

## 敌人动作帧

```text
生成一张 2D 俯视角敌人 sprite sheet，纯绿色背景 #00ff00。

保持同一个敌人：小型机械感染体，黑色外壳，尖刺轮廓，电粉主描边，少量青蓝机械细节。严格保持帧间一致性。

动作：walk 8 帧，attack 4 帧，hit 3 帧，death 4 帧。所有帧规则网格排列，每帧大小一致、中心点一致、间距均匀。

风格：手绘涂鸦，粗黑轮廓线，克制电粉霓虹描边，不要大面积泛光。不要文字、不要水印、不要 UI、不要复杂背景。
```

## 负面提示词

```text
避免：写实风格、照片级真实、厚重 3D 渲染、像素风、体素、柔和渐变、厚涂、过度光晕、满屏霓虹、强烈泛光、背景太亮、细节过碎、模糊线条、无轮廓线、复杂纹理、角色帧间不一致、文字、水印、logo。
```

## 执行原则

1. 线条优先，霓虹为辅。黑色轮廓必须清晰连续。
2. 地图最暗，障碍次暗，玩家/敌人亮，掉落物最亮。
3. 霓虹光晕不要全画在贴图里，Godot 里可用材质、Light2D 或 shader 辅助。
4. 动作帧先小批量验证，不要一次要求四方向 32 帧。
5. 玩家青蓝、敌人电粉、奖励黄色/青绿，颜色职责不要混用。
