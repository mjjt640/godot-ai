# Q 版奇幻竞技场美术基线

## 全局风格

```text
2D 俯视角 top-down survivor 游戏资产，Q 版奇幻竞技场，粗黑轮廓线，圆润比例，清晰大色块，轻量手绘质感。角色和怪物使用高饱和识别色，地图与装饰必须低饱和、低对比。参考素材库 C:\Users\admin\Desktop\C1827：小骑士、哥布林、兽人、火蛇、水蛇、Boss 警告横幅。不是赛博风，不要霓虹金属地板，不要科幻枪械，不要写实厚涂，不要像素风。
```

## 地图方向

```text
生成大型 16:9 俯视角 2D survivor 战斗地图背景。

风格：Q 版奇幻竞技场 / 魔法荒野。地图整体必须比角色和怪物更暗、更灰、更低饱和，主色为橄榄绿、泥土褐、旧石灰、枯草黄。允许少量暖色火焰、冷色水纹或淡蓝符文作为陷阱提示，但不能成为大面积主视觉。

地图设计：中心区域保持开阔，适合玩家拉扯、风筝敌人、绕圈移动。边缘可以有破旗、木栅栏、碎石、旧石柱、草丛和浅色石板圈。障碍物只做路线提示，不做复杂迷宫，不形成封闭死胡同。

视觉地标：至少 3 个低对比地标，例如破旧试炼石门、断裂旗杆、圆形石阵、废弃木台、浅色符文圈。所有地标都应贴近地面，不遮挡角色。

限制：不要角色、不要敌人、不要 UI、不要文字、不要水印。不要赛博、不要霓虹线路、不要金属实验室、不要复杂到看不清道路。
```

## 地图 Tile / 装饰素材板

```text
生成一张 2D 俯视角奇幻竞技场 tile 和装饰素材板，纯白背景 #ffffff。

风格：Q 版、粗黑轮廓、低饱和手绘。地图素材必须服务战斗可读性，不能比角色和怪物更亮。

内容：草地 tile、泥土地 tile、浅石板 tile、磨损竞技场圆环、碎石、短木桩、破旗、低矮木栅栏、旧石柱、草丛、浅色符文圈、火焰陷阱底座、水纹陷阱底座。

要求：所有物体独立摆放，留出足够间距，方便切图。俯视角统一，正交视角，无强透视。不要角色、不要 UI、不要文字、不要水印。
```

## 玩家设定图

```text
生成一张 2D 俯视角玩家角色设定图，纯白背景 #ffffff。

角色：Q 版奇幻小骑士或冒险者，圆润头身比例，粗黑轮廓，头盔、短披风、小盾牌、短剑或法杖。整体和 C1827 素材库的 p0001 风格一致。

识别色：玩家可以使用青绿、浅蓝、银灰、少量暖棕。颜色块要清晰，小尺寸下能一眼识别朝向和武器。

要求：俯视角或 3/4 俯视角，轮廓清楚，设计简洁，不要过多碎细节。不要文字、不要 UI、不要水印、不要场景背景。
```

## 玩家动作帧

```text
生成一张 2D 俯视角玩家角色 sprite sheet，透明背景或纯绿色背景 #00ff00。

保持同一个 Q 版小骑士：头盔、小盾牌、短剑或法杖、青绿/银灰主色。严格保持帧间一致性，不要换脸、换发型、换衣服、换武器。

动作：优先 idle、move、attack、hit、death。所有帧规则网格排列，每帧大小一致、中心点一致、脚底基准线一致、间距均匀。

风格：粗黑轮廓，圆润比例，高可读大色块。不要赛博配件、不要枪械、不要霓虹外发光、不要复杂背景。
```

## 敌人设定图

```text
生成一张 2D 俯视角敌人设定图，纯白背景 #ffffff。

敌人：Q 版哥布林、兽人、骷髅兵、蛇形陷阱或小型魔物。整体形状比玩家更尖锐，但仍保持圆润卡通比例。参考 C1827 的 m100xx 和 m200xx 系列。

识别色：小怪优先青绿、蓝、土黄；精英和 Boss 可用更强的黄、橙、红、紫。黑色外轮廓必须稳定清晰。

要求：俯视角或 3/4 俯视角，小尺寸下能看出朝向和威胁感。不要文字、不要水印、不要场景背景。
```

## 敌人动作帧

```text
生成一张 2D 俯视角敌人 sprite sheet，透明背景或纯绿色背景 #00ff00。

保持同一个敌人：Q 版奇幻魔物，粗黑轮廓，高饱和主体色，帧间一致。

动作：idle、move、attack、hit、death。优先复用 C1827 已有命名习惯：idle、move、attack01、suffer、death、born、skill。

风格：圆润卡通比例，动作夸张但轮廓稳定。不要赛博机械、不要霓虹边线、不要复杂背景。
```

## 负面提示词

```text
避免：赛博废土、科幻实验室、金属地砖、霓虹线路、枪械、照片级真实、厚重 3D 渲染、像素风、体素、柔和无轮廓、过度光晕、背景太亮、细节过碎、角色帧间不一致、文字、水印、logo。
```

## 执行原则

1. 角色和怪物是最高对比对象，地图永远退后。
2. 黑色轮廓必须清晰连续，颜色块要大，细节要少。
3. 地图第一版优先程序化低饱和底板，不急于导入复杂地砖。
4. 动作帧先小批量验证，不要一次要求所有方向和所有动作。
5. C1827 是当前风格主参考；项目内旧赛博和旧 sheet 资产不得继续作为新资源基线。
